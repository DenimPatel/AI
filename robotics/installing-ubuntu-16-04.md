# Installing Ubuntu 16.04

*March 24, 2017 · Uncategorized*

---

First of all, before installing Ubuntu as a dual boot here is the minimum specs required in your laptop for working with ROS.

Processing : i5 5th gen  (2 GHz above)

Ram : 4 GB

HDD  free Space :100 GB

( Here I am suggesting to allocate 100 GB HDD space just because to run and to debug the data you will save your entire project or the sensor data as a bag file. Otherwise less space is not an issue. )

For Installation please make sure that you should have one 2 GB (or Above) Pen Drive with you.

Okay than,Lets start start installing the Ubuntu 16.04.There are 3 processes involved.

- Downloading Ubuntu & making bootable Pen Drive
- Making of partition of your HDD
- Installation

1.) Now install Ubuntu 16.04 from the Official site from the link given below:

**[Ubuntu\_16.04\_download](https://www.ubuntu.com/download/desktop) (1.4 GB)**

To make bootable Pen Drive install software Rufus from the link given below:

**[Rufus\_official\_download](https://rufus.akeo.ie/)  (1 MB)**

After Downloading Rufus just install it.

Follow the **[step wise process](https://www.ubuntu.com/download/desktop/create-a-usb-stick-on-windows)** for making the bootable Pen Drive given on official site of Ubuntu.

**That's it !! (33% done)**

2.)For partitioning the HDD you can use the windows's inbuilt software,

**" Disk management "**

 The process is easy but if you are doing it for the first time than I advise you to follow the **[steps given here](http://www.disk-partition.com/windows-10/windows-10-disk-management-0528.html)**.

3.) Installation process you can do it if you have done it for windows. But just for the reference while installation you can have **[this guide](https://www.ubuntu.com/download/desktop/install-ubuntu-desktop)** with you in other device.

![74](https://roboticswithdenim.wordpress.com/wp-content/uploads/2017/03/74.jpg)

Congratulations!! Now You are good to go to the next page for installing ROS.
