For Downloading ROS on your laptop you have 3 choices of installation

- Basic (only build and communication libraries. No GUI tools.)
- Desktop ( ROS with GUI tools)
- Desktop-Full (  ROS, GUI, robot-generic libraries, 2D/3D simulators, navigation and 2D/3D perception)

I prefer that you Install the **Desktop-Full** Version of ROS Kinetic.

To download the ROS, We are going to use the **Terminal**.

You can open terminal from Application list or from short-cut (**Ctrl + Alt + T)**

Remember the short-cut of opening terminal because we will using it a lot.

The Installation Process is fully documented on official wiki page : **[Installation Procedure](http://wiki.ros.org/kinetic/Installation/Ubuntu)**

Just following it is a wise option.

When your are done with the ROS Installation, you are now ready to learn the basics of ROS.
