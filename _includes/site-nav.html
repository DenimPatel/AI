{%- comment -%} Single global nav for every page type: layout-driven markdown pages, robotics articles, and the section hubs. Pages mark their subject with `section: ai|vision|robotics` in front matter. Rendered as a sticky top bar on wide screens and an off-canvas drawer on narrow ones. Collapsing it hides the primary links down to the bar's controls rather than to an icon rail — the collapsed/expanded state is remembered per browser via localStorage; the mobile drawer state is not persisted. The class and id contract is unchanged from the sidebar this replaced: `.nav`, `#site-nav`, `.nav-head`, `.nav-brand`, `.nav-brand-dot`, `.nav-collapse-toggle`, `.nav-mobile-toggle`, `.nav-mobile-toggle-bar`, `.nav-scrim` — because assets/css/styles.css and assets/css/chrome.css both target them by name. What changed is the geometry, and that lives in assets/css/chrome.css at `#site-nav` specificity.
